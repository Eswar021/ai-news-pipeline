Where the intelligence & the spend live

Every LLM call-site, its model, and the cheaper option

The map above shows where the models are; this is the decision table. Prices are per 1M tokens (input / output), Aug 2026. The pattern is already sound — cheap models do the bulk work, the pricey gpt-4o is concentrated in script planning. That's the one place worth trimming.

Module · roleModelPrice in / outTierCheaper & reliable option
script_generation · director + source-researcher + bookendsgpt-4o$2.50 / $10.00priceyBookends & researcher → gpt-4o-mini (~16× cheaper out). Director → keep quality on gpt-5.4-nano or DeepSeek. A/B the director.
topic_research · framergpt-4o$2.50 / $10.00priceyTrivial task (make search queries) → gpt-4o-mini. Safe swap.
metadata_creator · fallback onlygpt-4o$2.50 / $10.00rareOnly fires on a DeepSeek miss → leave, or gpt-4o-mini.
editorial_triage / story_mapping / editorial_selectiongpt-4o-mini$0.15 / $0.60cheapAlready the cheapest tier. Leave as-is.
script writers/reviewers · topic synth · metadata · art-directordeepseek-v4-pro$0.44 / $0.87cheapCheap reasoning workhorse; cache-hit input ≈ free. Keep.
story_mapping · clusteringall-MiniLM-L6-v2on-devicefreeLocal, no API. Keep.
voiceover · production TTSgemini-3.1-flash-tts$1 / $20 · ~$0.03/minmidgpt-4o-mini-tts ~½ the cost, or gemini-3.5-flash-tts ~⅓ — both need a voice A/B.

Bottom line: six of seven call-sites are already on the cheap tier (gpt-4o-mini, DeepSeek, or local). The single lever is the gpt-4o block in script planning + the topic framer — moving the low-risk roles to gpt-4o-mini and A/B-testing the director is where the OpenAI credit savings are. At ~2 episodes/day the absolute spend is a few dollars/month either way, so reliability & quality, not raw cost, are the deciding factors.
